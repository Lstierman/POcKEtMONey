How the catalog is stored

Every card is packed into a positional tuple (no repeated field names, image URLs shortened to a 2-letter host code). The whole catalog ships gzip-compressed inside the page: 9.6 MB of card data in about 2.6 MB. Live updates from GitHub are saved in IndexedDB, one record per set, so an update only rewrites the sets that changed.

On open, the page builds an inverted index: a sorted term dictionary with a Uint32Array posting list per term. Prefix lookups are a binary search plus a contiguous scan.

Filters are bitmaps, one bit per card. Combining filters is a word-by-word AND over ~650 32-bit words, and the live counts on the chips are popcounts of those ANDs. Typos fall back to an edit-distance match over the dictionary.

Prices are a snapshot taken when the page was built. Each language is its own card: Japanese prints have their own entries and their own Cardmarket prices. English cards show TCGplayer (US market, English copies only) and Cardmarket (Europe). Cardmarket's public price guide pools all European languages of a card, so a German or French copy can sell above or below the figure shown.

Query syntax: price>50 eur<5 usd>=100 lang:ja name: artist: set: attack: rarity: type: reg: hp>=120 dex:25 no:4, quotes for multi-word values, -word to exclude.
